# Grady 采集（只读）

装在你平时登录各平台的浏览器里。每天北京时间 9 点以后的第一次机会，它把各平台创作后台的列表页读一遍，把每篇的阅读、互动和各平台粉丝数交给本机的工作台。

它只读页面上已经显示的文字：不点按钮、不填表、不发布，也不用调试权限。一次只开一个页面，读完就关。

## 读哪些页面

| 平台 | 页面 |
|---|---|
| X | 你的个人主页 |
| 抖音 | 创作者中心首页、作品管理 |
| 小红书 | 创作服务平台首页、笔记管理 |
| B站 | 创作中心的图文管理；粉丝数问 B站自己的公开接口 |
| 公众号 | 后台首页 |

某个平台在这个浏览器里没登录，它记下来以后不再打开；点一下工具栏上的图标会全部重试。

## 安装

1. 把 `token.example.js` 复制成 `token.js`，填工作台 `config.json` 里的 `web.collectToken` 和你的 X 用户名。
2. 浏览器打开扩展管理页（Edge 是 `edge://extensions`），打开“开发人员模式”，点“加载解压缩的扩展”，选这个文件夹。
3. 几个平台分在不同的浏览器配置里登录的话，每个配置各装一次。
4. 点一下工具栏上的图标，马上采一次。图标上出现“✓”是交给工作台了，“!”是工作台没开，下次会补交。

## 数据怎么对上文章

工作台按这些办法把读数对到已登记的文章上，对不上的条目（短帖、还没登记的文章）不入库：

- X：帖子编号对链接
- 公众号：标题
- 其余平台：发布时间，精确到分

## 公众号掉登录：把登录码发到微信（2026-11-22）

- 读公众号时打开的是扫码登录页，插件就把页面上的登录二维码画成 PNG 交给工作台（`POST /api/collect/qr`），工作台经微信网关 `wx-notify --file` 发到作者微信；作者在手机上直接扫。插件让这个页面开着等最多 4 分钟，扫完接着在同一页面读数据。
- 作者太久没在微信里说话（腾讯拒收主动消息）时不发图，改发一句文字“回我一句话我就把登录码发过来”（一天一次）。之后插件每 30 分钟问一次工作台（`GET /api/collect/login-wanted`）：公众号还没登录、作者 3 小时内说过话、两小时内没发过码，就再走一次。
- 两小时内最多自动发一张码；点工具栏图标手动采时不受这个限制。
